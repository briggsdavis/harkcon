# Harkcon admin setup

The admin application lives at `/admin`. Authentication, content, contacts, and analytics are stored in Convex.

## Required environment variables

Set these on every Convex deployment (development and production):

- `ADMIN_ALLOWED_EMAILS`: comma-separated email addresses permitted to create and use admin accounts.
- `SITE_URL`: the public site origin, such as `https://www.harkcon.com`.
- `BETTER_AUTH_SECRET`: a securely generated random secret of at least 32 bytes.

The Next.js deployment also needs the values generated by Convex:

- `NEXT_PUBLIC_CONVEX_URL`
- `NEXT_PUBLIC_CONVEX_SITE_URL`

Example commands:

```sh
npx convex env set ADMIN_ALLOWED_EMAILS "person@harkcon.com,other@harkcon.com"
npx convex env set SITE_URL "https://www.harkcon.com"
npx convex env set BETTER_AUTH_SECRET "<secure-random-secret>"
```

## Initial content migration

After the first Convex deployment, run this once:

```sh
npx convex run seed:initialContent
```

The seed is idempotent and imports the existing six news articles, eight “Harkcon in the News” entries, three news topics, and seven solution page records. The public site retains its built-in news fallback until the seed is available.

## Deployment note

Newly created article URLs are dynamic, so the Next.js app now requires a normal Next.js-capable host rather than a static-export-only host.
